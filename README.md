# スマート視差距離計 (Smart Rangefinder - Phone Only)

物理的なカードの印刷や作成を一切必要とせず、**スマートフォン1台（iPhone / Android）とインカメラだけで視差を利用した簡易距離測定**を行えるWebアプリケーションです。

## 🌟 主な特徴
- **完全カードレス**: 面倒な紙のカード作成・切り取りが不要。スマホ画面上の目盛りをそのまま利用できます。
- **インカメラによる身体測定（自動校正）**:
  - **瞳孔間距離 (PD) 測定**: インカメラと顔の比率から、個人のPD（mm）を自動推定・設定。
  - **腕の長さ測定**: 画面と目の距離（腕の長さ）を光学的に算出して自動反映。
- **選べる2つの測定モード**:
  - **デジタルカード目盛りモード**: 画面上に表示される距離目盛りを覗き込んで測定。
  - **タップ対話測定モード**: スマホを見つめながら左右の目の視差ズレを画面上のラインに合わせることで直感的に距離を算出。
- **多言語対応**: 日本語 ⇄ 英語 の切り替えに対応。

## 📱 動作環境
- モダンなブラウザ（Safari, Chromeなど）を搭載したスマートフォン（iPhone / Android）
- インカメラ（フロントカメラ）を利用するため、HTTPS環境（または localhost）でのホスティングが必要です。
